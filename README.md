# Waste Classification System

This project is a deep learning-based waste classification system that classifies waste images into different categories using Convolutional Neural Networks (CNN). The model is trained on image datasets and evaluated using accuracy and confusion matrix metrics.

## Features
- Image-based waste classification
- CNN model training and evaluation
- Accuracy and confusion matrix visualization
- TensorFlow/Keras implementation
- Dataset preprocessing and augmentation

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- OpenCV

## Results
The model achieves high classification accuracy on the validation dataset and provides graphical evaluation metrics.
